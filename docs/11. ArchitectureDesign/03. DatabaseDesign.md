# Database Design

> Working paper. **Approved schema:** [`FInal/02. ERD.md`](FInal/02.%20ERD.md). No physical FKs across services.

PostgreSQL + Database-per-Service, consistent with the Microservices + DDD architecture

## Database Architecture
```
                         Banking Digital Wallet
                                  │
             ┌────────────────────┼────────────────────┐
             │                    │                    │
             ▼                    ▼                    ▼
       Identity DB          Customer DB           Wallet DB
             │                    │                    │
        PostgreSQL           PostgreSQL           PostgreSQL
             │                    │                    │
             ▼                    ▼                    ▼
       Transfer DB         Payment DB             Ledger DB
             │                    │                    │
        PostgreSQL           PostgreSQL           PostgreSQL
             │                    │                    │
             └────────────────────┼────────────────────┘
                                  │
                         Admin / Risk DB
                                  │
                             PostgreSQL
```

## Database Decomposition
| Database          | Owned By                 | Main Tables                                             |
| ----------------- | ------------------------ | ------------------------------------------------------- |
| `identity_db`     | Identity Service         | users, credentials, refresh_tokens, sessions            |
| `customer_db`     | Customer/KYC Service     | customers, kyc_applications, kyc_documents              |
| `wallet_db`       | Wallet Service           | wallets, wallet_limits, deposits, withdrawals           |
| `transfer_db`     | Transfer Service         | transfers, beneficiaries                                |
| `payment_db`      | Payment/Merchant Service | merchants, payments, qr_codes, refunds                  |
| `ledger_db`       | Ledger Service           | ledger_accounts, financial_transactions, ledger_entries |
| `risk_db`         | Risk Service             | risk_assessments, fraud_alerts                          |
| `notification_db` | Notification Service     | notifications, notification_preferences                 |
| `admin_db`        | Admin Service            | admin_users, roles, permissions, audit_logs, approvals  |

## SQL Scripts — PostgreSQL
### Wallet SQL
**_wallet-service/V1__create_wallet_schema.sql_**
**Wallet**
```
CREATE EXTENSION IF NOT EXISTS pgcrypto;

CREATE TABLE wallets (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),

    customer_id UUID NOT NULL,

    wallet_number VARCHAR(50) NOT NULL UNIQUE,

    currency CHAR(3) NOT NULL,

    status VARCHAR(20) NOT NULL DEFAULT 'ACTIVE',

    available_balance NUMERIC(19,4) NOT NULL DEFAULT 0,

    reserved_balance NUMERIC(19,4) NOT NULL DEFAULT 0,

    version BIGINT NOT NULL DEFAULT 0,

    created_at TIMESTAMP WITH TIME ZONE NOT NULL DEFAULT CURRENT_TIMESTAMP,

    updated_at TIMESTAMP WITH TIME ZONE NOT NULL DEFAULT CURRENT_TIMESTAMP,

    CONSTRAINT chk_wallet_balance
        CHECK (available_balance >= 0),

    CONSTRAINT chk_wallet_reserved_balance
        CHECK (reserved_balance >= 0),

    CONSTRAINT chk_wallet_currency
        CHECK (currency IN ('THB', 'USD', 'EUR', 'JPY')),

    CONSTRAINT chk_wallet_status
        CHECK (status IN ('ACTIVE', 'FROZEN', 'CLOSED'))
);
```

**Wallet Limits**
```
CREATE TABLE wallet_limits (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),

    wallet_id UUID NOT NULL UNIQUE,

    daily_transfer NUMERIC(19,4) NOT NULL DEFAULT 100000,

    daily_withdrawal NUMERIC(19,4) NOT NULL DEFAULT 50000,

    daily_deposit NUMERIC(19,4) NOT NULL DEFAULT 200000,

    single_transfer NUMERIC(19,4) NOT NULL DEFAULT 100000,

    single_withdrawal NUMERIC(19,4) NOT NULL DEFAULT 50000,

    created_at TIMESTAMP WITH TIME ZONE NOT NULL DEFAULT CURRENT_TIMESTAMP,

    updated_at TIMESTAMP WITH TIME ZONE NOT NULL DEFAULT CURRENT_TIMESTAMP,

    CONSTRAINT fk_wallet_limits_wallet
        FOREIGN KEY (wallet_id)
        REFERENCES wallets(id)
        ON DELETE CASCADE,

    CONSTRAINT chk_daily_transfer
        CHECK (daily_transfer > 0),

    CONSTRAINT chk_daily_withdrawal
        CHECK (daily_withdrawal > 0),

    CONSTRAINT chk_daily_deposit
        CHECK (daily_deposit > 0)
);
```

**Deposits**
```
CREATE TABLE deposits (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),

    wallet_id UUID NOT NULL,

    amount NUMERIC(19,4) NOT NULL,

    currency CHAR(3) NOT NULL,

    status VARCHAR(20) NOT NULL DEFAULT 'PENDING',

    reference VARCHAR(100) NOT NULL UNIQUE,

    created_at TIMESTAMP WITH TIME ZONE NOT NULL DEFAULT CURRENT_TIMESTAMP,

    completed_at TIMESTAMP WITH TIME ZONE,

    CONSTRAINT fk_deposits_wallet
        FOREIGN KEY (wallet_id)
        REFERENCES wallets(id),

    CONSTRAINT chk_deposit_amount
        CHECK (amount > 0),

    CONSTRAINT chk_deposit_status
        CHECK (
            status IN (
                'PENDING',
                'COMPLETED',
                'FAILED',
                'CANCELLED'
            )
        )
);
```

CREATE TABLE beneficiaries (

```
CREATE TABLE ledger_entries (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),

    financial_transaction_id UUID NOT NULL,

    ledger_account_id UUID NOT NULL,

    entry_type VARCHAR(10) NOT NULL,

    amount NUMERIC(19,4) NOT NULL,

    created_at TIMESTAMP WITH TIME ZONE NOT NULL DEFAULT CURRENT_TIMESTAMP,

    CONSTRAINT fk_ledger_transaction
        FOREIGN KEY (financial_transaction_id)
        REFERENCES financial_transactions(id),

    CONSTRAINT fk_ledger_account
        FOREIGN KEY (ledger_account_id)
        REFERENCES ledger_accounts(id),

    CONSTRAINT chk_entry_type
        CHECK (entry_type IN ('DEBIT', 'CREDIT')),

    CONSTRAINT chk_entry_amount
        CHECK (amount > 0)
);
```
