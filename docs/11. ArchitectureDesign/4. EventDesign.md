# Event Design
## Event Architecture
**The overall flow:**
```
┌──────────────────┐
│   Wallet Service │
└────────┬─────────┘
         │
         │ MoneyDeposited
         ▼
┌──────────────────┐
│      Kafka       │
└────────┬─────────┘
         │
    ┌────┼───────────────┐
    ▼    ▼               ▼
Notification  Ledger   Audit
 Service      Service   Service
```

**For transfers:**
```
Transfer Service
       │
       │ TransferCompleted
       ▼
     Kafka
       │
       ├──────────────► Notification Service
       │
       ├──────────────► Audit Service
       │
       └──────────────► Analytics/Risk Service
```

## Event Categories
| Category     | Examples                             |
| ------------ | ------------------------------------ |
| Identity     | UserRegistered, UserLoggedIn         |
| Customer/KYC | CustomerCreated, KycApproved         |
| Wallet       | WalletCreated, MoneyDeposited        |
| Transfer     | TransferInitiated, TransferCompleted |
| Payment      | PaymentCompleted, RefundCompleted    |
| Ledger       | LedgerTransactionPosted              |
| Risk         | FraudAlertCreated                    |
| Notification | NotificationCreated                  |
| Admin        | WalletFrozen, CustomerBlocked        |
| Security     | PasswordChanged, LoginFailed         |

## Identity Events
### UserRegistered
Published when a user successfully creates an account.
> Event: UserRegistered  
> Producer: Identity Service  
> Topic: identity.user-registered  

**Payload:**
```
{
  "eventId": "uuid",
  "eventType": "UserRegistered",
  "occurredAt": "2026-08-18T10:00:00Z",
  "version": 1,
  "userId": "uuid",
  "email": "customer@example.com",
  "phoneNumber": "+668xxxxxxxx",
  "correlationId": "uuid"
}
```

**Consumers**
- Customer Service
- Notification Service
- Audit Service

**Flow:**
```
User Registration
       │
       ▼
Identity Service
       │
       ▼
UserRegistered
       │
       ▼
Kafka
 ┌─────┼──────────┐
 ▼     ▼          ▼
Customer Notification Audit
```

### UserLoggedIn
> Event: UserLoggedIn  
> Producer: Identity Service  
> Topic: identity.user-logged-in  

**Payload:**
```
{
  "eventId": "uuid",
  "eventType": "UserLoggedIn",
  "userId": "uuid",
  "deviceId": "device-123",
  "ipAddress": "xxx.xxx.xxx.xxx",
  "occurredAt": "2026-08-18T10:05:00Z"
}
```

**Consumers**
- Risk Service
- Audit Service
- Notification Service

**Help Detect:**
```
New Device Login
Suspicious IP
Unusual Login
```

### PasswordChanged
> Event: PasswordChanged  
> Producer: Identity Service  
> Topic: identity.password-changed  

**Consumers**
- Notification Service
- Audit Service
- Security/Risk Service

### MoneyDeposited
**Producer:**
> Wallet Service

**Payload:**
```
{
  "eventId": "uuid",
  "eventType": "MoneyDeposited",
  "eventVersion": 1,
  "walletId": "wallet-uuid",
  "customerId": "customer-uuid",
  "transactionId": "transaction-uuid",
  "reference": "DEP-20260818-001",
  "amount": 10000.00,
  "currency": "THB",
  "occurredAt": "2026-08-18T10:30:00Z",
  "correlationId": "uuid"
}
```

**Consumers**
- Ledger Service
- Notification Service
- Audit Service
- Risk Service

**Flow:**
```
Deposit
   │
   ▼
Wallet Service
   │
   ├── Update Balance
   │
   └── Outbox Event
           │
           ▼
     MoneyDeposited
           │
           ▼
         Kafka
       ┌───┼────┐
       ▼   ▼    ▼
    Ledger Notify Audit
```

## Transfer Events
### TransferInitiated
Published when a transfer request is accepted for processing.
```
Customer
   │
   ▼
POST /transfers
   │
   ▼
Transfer Service
   │
   ▼
TransferInitiated
```

**Payload:**
```
{
  "eventId": "uuid",
  "eventType": "TransferInitiated",
  "transferId": "uuid",
  "senderCustomerId": "uuid",
  "receiverCustomerId": "uuid",
  "amount": 10000.00,
  "currency": "THB",
  "reference": "TRF-20260818-001",
  "occurredAt": "2026-08-18T11:10:00Z"
}
```
